# 获取设备属性信息接口：
地址：/api/iot/device/property
请求方式：Post
描述：获取设备属性信息
请求参数：
字段：deviceImei  类型：String  必填：true   描述：设备imei
字段：itemType  类型：Integer  必填：true   描述：属性类型，0心率，1血氧，2血压，3体温，4步数
字段：queryType  类型：Integer  必填：true   描述：查询类型，0日，1周，2月，3年
字段：eventStartDate  类型：String  必填：true   描述：事件开始日期
字段：eventEndDate  类型：String  必填：true   描述：事件结束日期

请求参数说明：
{
	"deviceImei":"869975030003275",
	"itemType":0,
	"queryType":0,
	"eventStartDate":"2026-07-25",
	"eventEndDate":"2026-07-25"
}
返回结果：
{
	"code": "OK",
	"success": true,
	"message": {"data":[
		{
			"events":[
				{

接口逻辑：
1.从数据库表iot_device_types中查询所有设备类型（status为1启用的数据），返回至前端。


# 表结构说明
## iot_user_devices 用户设备关系表
字段 字段类型 必填 说明
id Long true 主键id
userId Long true 用户id
deviceId Long true 设备id
deviceImei String true 设备imei
status Long true 状态 0-禁用 1-启用
createTime DateTime true 创建时间
updateTime DateTime true 更新时间

## iot_device_types表结构：
字段 字段类型 必填 说明
id Long true 主键id
code String true 设备类型编码
name String true 设备类型名称
status Long true 状态 0-禁用 1-启用
createTime DateTime true 创建时间
updateTime DateTime true 更新时间
