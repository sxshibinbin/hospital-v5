# 指标详情趋势接口设计

## 背景

健康监测指标详情页需要按日、周、月、年查看趋势数据。页面默认打开时展示当前日期的日维度趋势；点击周、月、年后按对应时间范围重新请求接口；点击日期组件切换日期、时间段、月份或年份后再次请求接口。

接口需要同时兼容普通指标和血压指标：

- 普通指标：心率、血氧饱和度、体温、步数，返回单条趋势序列。
- 血压指标：返回高压、低压两条趋势序列。
- 日维度展示采集点趋势。
- 周、月、年维度展示聚合趋势，包含平均值、最小值、最大值，方便前端显示范围柱和平均线。
- 步数指标按合计值展示趋势，不显示范围柱。
- 非步数指标的周、月、年维度必须同时返回趋势点平均值和当前查询时间段总体平均值。

## 接口定义

地址：`/api/iot/device/metric/trend`

请求方式：`POST`

描述：获取单设备单指标趋势详情数据。

## 请求参数

| 字段 | 类型 | 必填 | 描述 |
|---|---|---:|---|
| userId | Long | 是 | 用户 ID；正式登录后也可从 token 中获取，用于校验设备归属 |
| deviceImei | String | 是 | 设备 IMEI |
| itemType | Integer | 是 | 指标类型：0 心率，1 血氧饱和度，2 血压，3 体温，4 步数 |
| queryType | Integer | 是 | 查询维度：0 日，1 周，2 月，3 年 |
| startDate | String | 是 | 查询开始日期，格式 `yyyy-MM-dd` |
| endDate | String | 是 | 查询结束日期，格式 `yyyy-MM-dd` |

## 日期传参规则

| 维度 | queryType | 前端传参规则 | 后端聚合粒度 |
|---|---:|---|---|
| 日 | 0 | `startDate = endDate = 选择日期`；默认当前日期 | 普通指标按小时或实际采集点返回；步数按小时合计返回 |
| 周 | 1 | 传时间段开始日期和结束日期；最多 7 天 | 按天聚合 |
| 月 | 2 | 传所选月份首日到末日 | 按天聚合 |
| 年 | 3 | 传所选年份 `01-01` 到 `12-31` | 按月聚合 |

后端校验：

- `startDate` 不能大于 `endDate`。
- 周维度 `endDate - startDate + 1` 不能超过 7 天。
- 月维度建议校验开始和结束日期属于同一个自然月。
- 年维度建议校验开始和结束日期属于同一个自然年。
- 用户无权访问该 `deviceImei` 时返回失败。

## 请求示例

### 心率日维度

```json
{
  "userId": 1,
  "deviceImei": "869975030003275",
  "itemType": 0,
  "queryType": 0,
  "startDate": "2026-07-28",
  "endDate": "2026-07-28"
}
```

### 血压周维度

## 返回参数

| 字段 | 类型 | 描述 |
|---|---|---|
| code | String | `OK` 表示成功，`ERROR` 表示失败 |
| success | Boolean | 是否成功 |
| message.data | Object | 趋势详情数据 |

`message.data` 字段说明：

| 字段 | 类型 | 描述 |
|---|---|---|
| deviceImei | String | 设备 IMEI |
| itemType | Integer | 指标类型 |
| itemName | String | 指标名称 |
| queryType | Integer | 查询维度 |
| unit | String | 指标单位 |
| xAxisType | String | X 轴类型：`point`、`hour`、`day`、`month` |
| startDate | String | 查询开始日期 |
| endDate | String | 查询结束日期 |
| series | Array | 趋势序列。普通指标 1 条，血压 2 条 |
| latest | Object | 当前选中或最新一条数据摘要 |
| thresholds | Object | 前端渲染颜色和状态用的阈值 |

`series[]` 字段说明：

| 字段 | 类型 | 描述 |
|---|---|---|
| key | String | 序列标识。普通指标如 `heartRate`；血压为 `systolic`、`diastolic` |
| name | String | 序列名称 |
| unit | String | 单位 |
| summary | Object | 当前查询时间段的总体统计值 |
| points | Array | 趋势点列表 |

`series[].summary` 字段说明：

| 字段 | 类型 | 描述 |
|---|---|---|
| avgValue | Number | 当前查询时间段总体平均值。周、月、年维度前端用于展示“平均值” |
| totalValue | Number | 当前查询时间段合计值。步数指标使用 |
| minValue | Number | 当前查询时间段最小值 |
| maxValue | Number | 当前查询时间段最大值 |
| lastValue | Number | 当前查询时间段最后一次采集值 |
| reportTime | String | 最后一次采集时间 |
| count | Integer | 当前查询时间段有效数据数量 |
| status | String | 总体状态：`normal` 正常，`low` 偏低，`high` 偏高，`critical_low` 严重偏低 |

`series[].points[]` 字段说明：

| 字段 | 类型 | 描述 |
|---|---|---|
| label | String | X 轴显示文本，如 `00:00`、`7/28`、`7月` |
| bucketStart | String | 聚合桶开始时间，格式 `yyyy-MM-dd HH:mm:ss` |
| bucketEnd | String | 聚合桶结束时间，格式 `yyyy-MM-dd HH:mm:ss` |
| avgValue | Number | 当前桶平均值。周、月、年维度前端用于绘制平均趋势线；日维度如果按实际采集点返回，可等于采集值 |
| totalValue | Number | 当前桶合计值。步数指标使用：日为每小时合计，周/月为每天合计，年为每月合计 |
| minValue | Number | 最小值。用于周、月、年范围柱 |
| maxValue | Number | 最大值。用于周、月、年范围柱 |
| lastValue | Number | 当前桶内最后一次采集值 |
| reportTime | String | 当前桶内最后一次采集时间 |
| count | Integer | 当前桶内数据数量 |
| status | String | 状态：`normal` 正常，`low` 偏低，`high` 偏高，`critical_low` 严重偏低 |

## 页面展示字段校验

指标详情页展示需要和接口字段对应如下：

| 页面区域 | 日维度字段 | 周、月、年维度字段 | 说明 |
|---|---|---|---|
| 趋势线 | `series[].points[].avgValue` 或实际采集值 | `series[].points[].avgValue` | 周、月、年按桶平均值画趋势线 |
| 步数趋势线 | `series[].points[].totalValue` | `series[].points[].totalValue` | 步数按合计值画趋势线，不显示范围柱 |
| 范围柱 | 可不展示，或 `minValue = maxValue = avgValue` | `series[].points[].minValue`、`series[].points[].maxValue` | 周、月、年展示每天或每月的范围；步数不显示范围柱 |
| tooltip | 当前点 `label`、`avgValue`、`minValue`、`maxValue` | 当前桶 `label`、`avgValue`、`minValue`、`maxValue` | 血压分别读取高压、低压两个 series |
| 详情卡当前点 | 当前点 `avgValue` 或 `lastValue` | 当前桶 `avgValue`、`minValue`、`maxValue` | 点击趋势点后展示 |
| 时间段平均值 | 可使用 `series[].summary.avgValue` | 必须使用 `series[].summary.avgValue` | 周、月、年必须返回，用于展示当前时间段总体平均值 |
| 最新值 | `latest.values` | `latest.values` | 页面需要默认选中最新点时使用 |

结论：周、月、年维度必须返回两类平均值：

1. `series[].points[].avgValue`：每个聚合桶的平均值，用于画趋势线。
2. `series[].summary.avgValue`：本次查询整个时间段的总体平均值，用于页面展示“平均值”。

步数指标例外：

1. `series[].points[].totalValue`：每个聚合桶的步数合计值，用于画趋势线。
2. `series[].summary.totalValue`：本次查询整个时间段的步数总数。
3. 步数不需要返回范围柱所需的 `minValue`、`maxValue`；如为统一结构保留字段，可返回 `null`。

## 血氧阈值返回示例

血氧饱和度需要支持三段颜色：

- `< 70%`：红色，状态 `critical_low`
- `70% - 89%`：橙色，状态 `low`
- `>= 90%`：绿色，状态 `normal`

```json
{
  "thresholds": {
    "criticalLow": 70,
    "safeLow": 90,
    "axisMax": 100
  }
}
```

## 指标映射

| itemType | itemName | 数据库 attr_name | series key | 单位 |
|---:|---|---|---|---|
| 0 | 心率 | 心率 | heartRate | 次/分 |
| 1 | 血氧饱和度 | 血氧 | spo2 | % |
| 2 | 血压 | 舒张压、收缩压 | diastolic、systolic | mmHg |
| 3 | 体温 | 温度 | temperature | ℃ |
| 4 | 步数 | 计步 | steps | 步 |

## 数据库查询注意事项

1. 查询表固定为 `iot_event_items`。
2. 日期检索字段固定使用 `sign_time`。
3. 指标类型和 `iot_event_items.attr_name` 的对应关系：

| itemType | 指标 | attr_name |
|---:|---|---|
| 0 | 心率 | 心率 |
| 1 | 血氧饱和度 | 血氧 |
| 2 | 血压 | 舒张压、收缩压 |
| 3 | 体温 | 温度 |
| 4 | 步数 | 计步 |

4. 血压需要分别查询 `舒张压`、`收缩压`，并分别输出为 `diastolic`、`systolic` 两条序列。
5. 步数指标按合计值返回：

| queryType | 查询维度 | 步数聚合方式 |
|---:|---|---|
| 0 | 日 | 合并每小时的步数总数返回 |
| 1 | 周 | 合并每天的步数总数返回 |
| 2 | 月 | 合并每天的步数总数返回 |
| 3 | 年 | 合并每月的步数总数返回 |

## 处理建议

1. 从 `iot_user_devices` 校验 `userId` 与 `deviceImei` 的绑定关系。
2. 从 `iot_event_items` 查询对应 `attr_name` 和 `sign_time` 范围内的数据。
3. 心率、血氧、体温按数值型解析 `attr_value`。
4. 非步数指标的周、月、年维度需要同时计算每个桶的 `points[].avgValue` 和整个查询时间段的 `series[].summary.avgValue`。
5. 步数日维度按小时合计，周和月维度按天合计，年维度按月合计；步数使用 `totalValue` 返回合计值，不显示范围柱。
6. 血压使用 `舒张压`、`收缩压` 两个 `attr_name`，分别输出 `diastolic`、`systolic` 两条序列。
7. 没有数据的桶建议返回该桶 `count = 0`，数值字段为 `null`；前端可以断线或显示空状态。

## 失败返回示例

```json
{
  "code": "ERROR",
  "success": false,
  "message": "周维度最多选择7天"
}
```
