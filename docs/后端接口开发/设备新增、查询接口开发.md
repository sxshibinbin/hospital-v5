# 新增设备接口：
地址：/api/iot/devices/add
请求方式：Post
描述：新增设备
请求参数：
字段：deviceImei  类型：String  必填：true   描述：设备imei
字段：deviceModelId  类型：Long  必填：true   描述：设备型号id
字段：deviceModelName  类型：String  必填：true   描述：设备型号名称
字段：roomName  类型：String  必填：true   描述：安装点名称
字段：deviceType  类型：String  必填：true   描述：设备类型名称
字段：userId  类型：Long  必填：true   描述：用户id
请求参数说明：
{
	"deviceImei":"869975030003275",
	"deviceModelId":33,
	"deviceModelName":“SM-C03”,
	"roomName": ”居然创客大厦“,
	"deviceType": “智能手环”,
	"userId":123456
}
返回结果：
{
	"code": "OK",
	"success": true,
	"message": {"data":"设备：869975030003275；添加成功！","deviceId":1213121}
}
接口逻辑：
1.根据传入的deviceImei调用平台的"查询-获取单个设备信息接口"校验设备是否存在；平台返回成功后，将前端提交的deviceModelId、deviceModelName、roomName、deviceType以及平台返回的设备信息存入数据库设备表iot_devices，并将平台返回的接警人信息存入iot_device_contacts。
2. 将用户id、deviceId、deviceImei、状态存入数据库用户设备关系表iot_user_devices。保存前先按user_id、device_id、device_imei查重；已存在且status不是1时更新为1；不存在时再插入。
3. 返回成功消息。
4. 失败时，返回失败消息。
平台接口详情如下：
1.查询-获取单个设备信息接口
描述：获取单个设备信息
请求方式：POST
请求 URL： http(s)://webapi.nbiotyun.com/api/v1/dev/get
请求参数
字段 字段类型 必填 说明
deviceId Long false 设备唯一ID
deviceImei String false 设备imei
fullFlag int true 全量查询标识 0:查询本级 1:查询所有
备注：deviceId 和 deviceImei 只需要传一个
请求参数说明
{
"deviceImei":"869975030003275",
"fullFlag":0
}
返回结果
{
"code": "OK",
"success": true,
"message": {"deviceId":1213121,"deviceImei":"869975030003275","deviceTypeName":"智能手环","deviceModelName":"SM-C03"}
}

# 获取设备类型字典接口：
地址：/api/iot/device/type_dict
请求方式：Get
描述：获取设备类型字典
请求参数：
无
返回结果：
{
	"code": "OK",
	"success": true,
	"message": {"data":["id":1,"code":“SM-C03”,"name":"智能手环"]}
}
接口逻辑：
1.从数据库表iot_device_types中查询所有设备类型（status为1启用的数据），返回至前端。

接口逻辑：
1. 根据用户id从iot_user_devices表中获取所有启动设备的设备id列表，根据设备id列表，从数据库表iot_devices、iot_device_events、iot_event_items中查询所有设备的设备imei、设备类型、设备版本、状态、安装点名称以及最新设备属性列表、上报时间，返回至前端。
2. state获取来源为iot_device_events表中最新一条数据的device_state字段值。
3. reportDate获取来源为iot_device_events表中最新一条数据的sign_time字段值。
4. items-reportDate获取来源为iot_event_items表中最新一条数据的sign_time字段值。
