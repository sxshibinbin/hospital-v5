# 获取单设备报警信息接口：
地址：/api/iot/devices/alarm
请求方式：Post
描述：获取单设备报警信息
请求参数：
字段：deviceImei  类型：String  必填：true   描述：设备imei
字段：handlerStatus  类型：Integer  必填：true   描述：处理状态，0未处理，1已处理
字段：eventStartDate  类型：String  必填：true   描述：事件开始日期
字段：eventEndDate  类型：String  必填：true   描述：事件结束日期

请求参数说明：
{
	"deviceImei":"869975030003275",
	"handlerStatus":0,
	"eventStartDate":"2026-07-25",
	"eventEndDate":"2026-07-25"
}
返回结果：
{
	"code": "OK",
	"success": true,
	"message": {"data":[
		{
			"deviceId":1213121,
			"deviceImei":"869975030003275",
			"deviceType":"智能手环",
			"roomName":"居然创客大厦",
			"events":[
				{
					"eventName":"事件名称",
					"data_type":2,
					"handlerStatus":0,
					"handlerTime":"2026-07-25 09:28",
          "alarmReason":"报警原因",
					"reportDate":"2026-07-25 09:28"
				},
				{
					"eventName":"事件名称",
					"data_type":2,
					"handlerStatus":0,  
					"handlerTime":"2026-07-25 09:28",
          "alarmReason":"报警原因",
					"reportDate":"2026-07-25 09:28"
				}
			]
		}
	]}
}
接口逻辑：
1.根据设备imei、处理状态、事件开始日期、事件结束日期查询查询数据库报警信息表iot_alarm_events中的报警信息，返回报警信息。
2.如果报警未处理（"handlerStatus":0），handlerTime和alarmReason为空，反之不为空。
3.接口支持查询全部报警信息、未处理报警信息、已处理报警信息。

# 获取设备信息接口：
地址：/api/iot/device/get
请求方式：Post
描述：获取设备信息接口
请求参数：
字段：deviceImei  类型：String  必填：true   描述：设备imei
请求参数说明：
{
	"deviceImei":"869975030003275"
}
返回结果：
{
	"code": "OK",
	"success": true,
	"message": {"data":
		{
			"deviceId":1213121,
			"deviceImei":"869975030003275",
			"deviceType":"智能手环",
			"deviceVersion":"SM-C03",
			"state":"正常",
			"roomName":"居然创客大厦",
			"reportDate":"2026-07-25 09:28"
		}
	}
}
接口逻辑：
1. 根据设备imei从数据库表iot_devices、iot_device_events、iot_event_items中查询设备的设备imei、设备类型、设备版本、状态、安装点名称以及最新设备属性列表、上报时间，返回至前端。

字段 字段类型 必填 说明
