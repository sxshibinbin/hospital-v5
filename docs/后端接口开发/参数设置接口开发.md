# 参数设置接口开发
## 查询设备参数接口：
地址：/api/iot/device/param/get
请求方式：Post
描述：查询设备参数
请求参数：
deviceImei：设备编号 必填
请求示例：
{
  "deviceImei": "867561087297571"
}
返回结果：
{
  "success": true,
  "code": "OK",
  "msg": "OK",
  "data": [
    {
        "paramCode": "654",
        "paramValue": "70"
    },
    {
        "paramCode": "655",
      "paramValue": "{\"start0\":\"22:00:00\", \"end0\":\"07:00:00\"}"
    }
  ]
}
代码实现逻辑：
1. 接口接收设备编号，查询数据库iot_device_params表中该设备的所有参数配置。
2. 返回查询结果。



## 设置设备参数接口：
地址：/api/iot/device/param/set
请求方式：Post
描述：设置设备参数
请求参数：
deviceImei：设备编号 必填
paramCode：参数编码 必填
paramValue：参数值 
createBy：创建人 必填
请求示例：
{
  "deviceImei": "867561087297571",
  "createBy": "admin",
  "data": [
    {
      "paramCode": "654",
      "paramValue": "70"
    },
    {
      "paramCode": "655",
      "paramValue": "{\"start0\":\"22:00:00\", \"end0\":\"07:00:00\"}"
    }
  ]
}
返回结果：
{
  "code": "OK",
  "success": true,
  "message": "设置成功"
}
代码实现逻辑：
1. 用户在设备设置页面配置参数，点击提交按钮后，调用该接口设置设备参数。
2. 接口接收参数后，先调用平台【创建指令下发任务接口】（注意：平台的接口不支持批量参数设置，只能拆分成多个参数调用；考虑到性能可以并发调用平台接口，待所有参数设置完成后，再同步写入数据库iot_device_params表中并返回成功），返回成功后，同步写入数据库iot_device_params表中。
3. 请求示例中的start0要保存到iot_device_params表中，paramCode为666，fieldName为start0，paramValue为22:00:00。
3. 返回设置成功结果。
注意：
1. iot_device_params表中imei和paramCode字段联合唯一，不能重复设置。
2. 调用平台【创建指令下发任务接口】时，不同参数的入参不一样，通用模式为：
{
  "paramCode": "654",
  "paramValue": "70",
}，其中paramCode为参数编码，paramValue为参数值；其余个性化的参数，请参考调用示例。

# 表结构

  │     字段     │     类型     │               说明               │
  ├──────────────┼──────────────┼──────────────────────────────────┤
  │ id           │ BigInteger   │ 主键                             │
  ├──────────────┼──────────────┼──────────────────────────────────┤
  │ imei         │ String(32)   │ 设备编号 (外键→iot_devices.imei) │
  ├──────────────┼──────────────┼──────────────────────────────────┤
  │ paramCode    │ String(32)   │ 参数编码                         │
  ├──────────────┼──────────────┼──────────────────────────────────┤
  │ fieldName    │ String(32)   │ 参数字段                           │
  ├──────────────┼──────────────┼──────────────────────────────────┤
  │ paramValue   │ String(64)   │ 参数值                           │
  ├──────────────┼──────────────┼──────────────────────────────────┤
