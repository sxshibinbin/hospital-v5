# 首次启动页开发说明

## 需求

App 首次启动时展示独立确认页，用户点击“同意并开始使用”后才可进入登录页。用户可点击“用户协议”“隐私政策”查看线上原文，原文弹窗仅用于查看，不展示同意/不同意按钮。

## 原型

- 原型文件：`docs/首次启动页/app-first-launch-agreement-prototype.html`
- 首屏主题：三十天时刻智护
- 主视觉：App 自带 logo
- 主题色：沿用 Flutter `AppTheme`
  - 主色：`#5B57F7`
  - 深色：`#2F266F`
  - 背景：`#F8F3FF` 到 `#FDF7F5`

## 协议地址

- 用户协议：`https://web.sstkjgf.com/user-agreement.html`
- 隐私政策：`https://web.sstkjgf.com/privacy-policy.html`

## 实现文件

- `flutter_app/lib/screens/first_launch_consent_screen.dart`
  - 首次启动页 UI
  - 用户协议/隐私政策 WebView 原文弹窗
  - 点击“同意并开始使用”后写入本地同意状态并跳转 `/login`

- `flutter_app/lib/providers/launch_consent_provider.dart`
  - 读取和维护首启同意状态
  - 对外暴露 `isLoading`、`hasAccepted`、`accept()`

- `flutter_app/lib/services/app_storage_service.dart`
  - 新增本地存储 key：`launch_consent_accepted`
  - 新增读写方法：`readLaunchConsentAccepted()`、`writeLaunchConsentAccepted(bool value)`

- `flutter_app/lib/router/app_router.dart`
  - 新增路由：`/launch-consent`
  - 初始路由改为 `/launch-consent`
  - 未同意时强制拦截到首启页
  - 已同意且未登录时跳转 `/login`

- `flutter_app/lib/main.dart`
  - 注册 `LaunchConsentProvider`
  - 路由同时监听登录状态和首启同意状态
  - 加载中继续展示全屏 loading 遮罩

- `flutter_app/test/widget_test.dart`
  - 测试中 mock `launch_consent_accepted = true`
  - 保持原“未登录显示登录页”测试目标

## 交互规则

1. 首次安装或本地未保存同意状态时，启动 App 进入 `/launch-consent`。
2. 点击“用户协议”打开用户协议原文弹窗。
3. 点击“隐私政策”打开隐私政策原文弹窗。
4. 原文弹窗只读展示，可关闭，不包含确认按钮。
5. 点击“不同意以下条款”提示“不同意条款将无法使用本应用”，不进入登录页。
6. 点击“同意并开始使用”后保存同意状态，并跳转 `/login`。
7. 后续启动读取到 `launch_consent_accepted = true` 后，不再展示首启页。
