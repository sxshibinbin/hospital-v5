# 对接功能
## 健康监测页面下的设备参数维护页面
逻辑：
1. 用户在健康监测页面下的设备参数维护按钮，打开设备参数维护页面时，根据当前设备imei，调用【查询设备参数接口】，按接口返回数据展示该设备的所有参数配置。
2. 修改参数信息点击【保存】按钮，调用【设置设备参数接口】，将修改后的参数配置保存到数据库iot_device_params表中。
注意：
1. 不同设备类型的参数配置不同，需要根据设备类型进行展示和设置。
2. 不同设备类型的参数值格式不同，需要根据设备类型进行解析和设置。例如：睡眠时间段参数值为JSON格式，需要解析为start0和end0两个字段。
3. 参数组装和解析请参考【设备参数与指令对应关系】，部分参数可直接通过”指令编码“区分，个别需要通过”指令编码“和”指令入参“共同确认。


# 参数设置接口开发
地址：http://localhost:8000
## 查询设备参数接口：
地址：/api/iot/device/param/get
请求方式：Get
描述：查询设备参数
请求参数：
deviceImei：设备编号 必填
请求示例：
{
  "deviceImei": "867561087297571"
}
返回结果：
{
  "success": true,
  "code": "OK",
  "msg": "OK",
  "data": [
    {
        "paramCode": "654",
        "paramValue": "70"
    },
    {
        "paramCode": "655",
      "paramValue": "{\"start0\":\"22:00:00\", \"end0\":\"07:00:00\"}"
    }
  ]
}


## 设置设备参数接口：
地址：/api/iot/device/param/set
请求方式：Post
描述：设置设备参数
请求参数：
deviceImei：设备编号 必填
paramCode：参数编码 必填
paramValue：参数值 
createBy：创建人 必填
请求示例：
{
  "deviceImei": "867561087297571",
  "createBy": "admin",
  "data": [
    {
      "paramCode": "654",
      "paramValue": "70"
    },
    {
      "paramCode": "655",
      "paramValue": "{\"start0\":\"22:00:00\", \"end0\":\"07:00:00\"}"
    }
  ]
}
返回结果：
{
  "code": "OK",
  "success": true,
  "message": "设置成功"
}

## 设置跌倒报警开关调用示例：
