# 当前登录用户信息获取方式

## 对接用途
移动应用中需要传入当前登录用户时，统一从 `AuthProvider` 获取，不要在页面中写死测试用户ID。

典型使用场景：
1. 查询当前用户绑定设备，例如 `/api/iot/device/report` 的 `userId`。
2. 新增设备时传入当前用户ID。
3. 调用需要登录态的接口时传入 `Authorization: Bearer <token>`。
4. 页面展示当前登录用户昵称、手机号、头像等基础信息。


## 移动端获取方式
### 页面展示中获取
需要页面随登录用户变化自动刷新时，使用 `watch`：

```dart
final authProvider = context.watch<AuthProvider>();
final currentUser = authProvider.currentUser;
```

### 事件方法或接口调用中获取
按钮点击、接口请求、初始化加载等不需要因用户变化自动重建当前方法时，使用 `read`：

```dart
final authProvider = context.read<AuthProvider>();
final currentUser = authProvider.currentUser;
final token = authProvider.token;
```

### 获取当前用户ID
后续接口需要 `userId` 时按下面方式获取：

```dart
final userId = context.read<AuthProvider>().currentUser?.id;
if (userId == null) {
  // 未登录或用户信息尚未加载完成，按业务跳转登录或提示
  return;
}
```

调用示例：

```dart
final authProvider = context.read<AuthProvider>();
final userId = authProvider.currentUser?.id;
if (userId == null) {
  return;
}

final response = await http.post(
  Uri.parse('http://localhost:8000/api/iot/device/report'),
  headers: {'Content-Type': 'application/json'},
  body: jsonEncode({'userId': userId}),
);
```

### 获取登录 token
需要鉴权的接口使用：

```dart
final token = context.read<AuthProvider>().token;
if (token == null || token.isEmpty) {
  return;
}

final headers = {
  'Authorization': 'Bearer $token',
  'Content-Type': 'application/json',
};
```


## 当前可获取字段
移动端 `CurrentUser` 当前包含以下字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `int` | 当前登录用户ID，对应后端 `users.id` |
| `phone` | `String` | 当前登录手机号 |
| `displayName` | `String` | 当前用户昵称 |
| `defaultProfileName` | `String?` | 默认健康档案名称，可能为空 |
| `avatarKey` | `String?` | 当前用户头像预设key，可能为空 |


## 数据来源
### 登录接口
登录成功后只返回 token，不直接返回完整用户信息。

密码登录：
```text
POST /api/auth/login
```

短信登录：
```text
POST /api/auth/login/sms
```

运营商一键登录：
```text
POST /api/auth/login/carrier
```

返回示例：

```json
{
  "access_token": "xxx",
  "token_type": "bearer"
}
```

### 当前用户接口
移动端拿到 token 后，会调用当前用户接口刷新用户信息：

```text
GET /api/auth/me
Authorization: Bearer <token>
```

返回示例：

```json
{
  "id": 1,
  "phone": "13800138000",
  "display_name": "用户8000",
  "default_profile_name": "本人",
  "avatar_key": "avatar_1"
}
```


## 本地缓存
移动端会把登录 token 和当前用户信息缓存在 `SharedPreferences`：

| 缓存key | 内容 |
| --- | --- |
| `auth_token` | 登录token |
| `auth_current_user` | 当前用户信息JSON |

应用启动时会先读取本地缓存；如果 token 存在，再自动调用 `/api/auth/me` 刷新当前用户信息。


## 注意事项
1. 后续页面接口对接时，不再使用固定 `userId = 1`，应统一使用 `AuthProvider.currentUser?.id`。
2. `currentUser` 可能为空，常见原因是未登录、登录初始化未完成、token 已失效或 `/api/auth/me` 刷新失败。
3. `isAuthenticated` 只表示 token 存在；如果业务必须拿到用户ID，应同时判断 `currentUser != null`。
4. 当前用户接口只返回账号基础信息，不返回完整健康档案。完整健康档案需要通过 `/api/profiles` 单独查询。
5. 登出时会清理 `auth_token`、`auth_current_user`、健康档案缓存、会话缓存和问诊记录缓存。
