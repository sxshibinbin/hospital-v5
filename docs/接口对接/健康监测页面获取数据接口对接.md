# 对接功能
## 健康监测页面
逻辑：点击左侧”健康监测“菜单进入健康监测页面时调用【获取设备检测信息列表接口】，传入当前登录用户id（测试阶段可传1）；根据返回参数提替换页面内容为动态信息；
注意：页面布局和样式不要动，没有数据文本显示空，数字显示0即可。

## 新增设备功能
逻辑：点击新增设备按钮，弹出新增设备页面时，调用【获取设备类型字典接口】获取设备类型字典，维护完成信息后，调用【新增设备接口】传入对应信息，用户id为当前登录用户id（测试阶段没有可传1）。
注意：【获取设备类型字典接口】返回的id、code、name字段，分别对应新增设备接口的deviceModelId、deviceModelName、deviceType字段。【新增设备接口】返回的deviceId字段，为新增设备的id。

## 获取设备类型字典接口：
地址：/api/iot/device/type_dict
请求方式：Get
描述：获取设备类型字典
请求参数：
无
返回结果：
{
	"code": "OK",
	"success": true,
	"message": {"data":["id":1,"code":“SM-C03”,"name":"智能手环"]}
}

## 新增设备接口：
地址：/api/iot/devices/add
请求方式：Post
描述：新增设备
请求参数：
字段：deviceImei  类型：String  必填：true   描述：设备imei
字段：deviceModelId  类型：Long  必填：true   描述：设备型号id
字段：deviceModelName  类型：String  必填：true   描述：设备型号名称
字段：roomName  类型：String  必填：true   描述：安装点名称
字段：deviceType  类型：String  必填：true   描述：设备类型名称
字段：userId  类型：Long  必填：true   描述：用户id
请求参数说明：
{
	"deviceImei":"869975030003275",
	"deviceModelId":33,
	"deviceModelName":“SM-C03”,
	"roomName": ”居然创客大厦“,
	"deviceType": “智能手环”,
	"userId":123456
}
返回结果：
{
	"code": "OK",
	"success": true,
	"message": {"data":"设备：869975030003275；添加成功！","deviceId":1213121}
}
