# 对接功能
## 报警记录页面
逻辑：
1. 点击健康监测页面的设备类型（如：正常），打开报警记录页面时调用【获取单设备报警信息接口】，传入设备imei，处理状态默认传0未处理，事件开始结束日期默认传当前日期（格式：yyyy-MM-dd），根据返回参数提替换页面内容为动态信息。
2. 点击”全部“报警记录，调用【获取所有报警记录接口】，传入设备imei，处理状态不传，事件开始结束日期默认传当前日期（格式：yyyy-MM-dd），根据返回参数提替换页面内容为动态信息。
2. 点击"已确认"报警记录，调用【获取所有报警记录接口】，传入设备imei，处理状态传1，事件开始结束日期默认传当前日期（格式：yyyy-MM-dd），根据返回参数提替换页面内容为动态信息。
2. 点击"未确认"报警记录，调用【获取所有报警记录接口】，传入设备imei，处理状态传0，事件开始结束日期默认传当前日期（格式：yyyy-MM-dd），根据返回参数提替换页面内容为动态信息。
注意：页面布局和样式不要动，没有数据文本显示空，数字显示0即可。


# 接口清单
调用地址：http://localhost:8000

## 获取单设备报警信息接口：
地址：/api/iot/devices/alarm
请求方式：Post
描述：获取单设备报警信息
请求参数：
字段：deviceImei  类型：String  必填：true   描述：设备imei
字段：handlerStatus  类型：Integer  必填：true   描述：处理状态，0未处理，1已处理
字段：eventStartDate  类型：String  必填：true   描述：事件开始日期
字段：eventEndDate  类型：String  必填：true   描述：事件结束日期

请求参数说明：
{
	"deviceImei":"869975030003275",
	"handlerStatus":0,
	"eventStartDate":"2026-07-25",
	"eventEndDate":"2026-07-25"
}
