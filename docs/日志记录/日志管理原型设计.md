# 日志管理原型设计

编写日期：2026-09-05

## 1. 原型文件

静态页面：

```text
docs/日志记录/log-management-prototype.html
```

打开方式：

- 可直接用浏览器打开 HTML 文件查看。
- 原型为静态展示，不连接真实接口。

## 2. 页面结构

日志管理页面延续 `admin_web` 当前后台布局：

- 左侧：后台菜单。
- 顶部：当前页面标题和管理员头像。
- 主区域：上方检索条件，下方日志表格列表。

## 3. 上方检索条件

检索区字段：

| 字段 | 控件 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 开始时间 | 日期时间输入框 | 最近 7 天起始 | 按日志创建时间筛选 |
| 结束时间 | 日期时间输入框 | 当天结束 | 按日志创建时间筛选 |
| 日志类型 | 下拉框 | 全部 | 登录登出、健康档案、后台管理等 |
| 操作类型 | 下拉框 | 全部 | 登录、登出、新增、修改、删除等 |
| 操作结果 | 下拉框 | 全部 | 成功、失败 |
| 操作人/用户 | 输入框 | 空 | 用户 ID、手机号后四位、管理员名称 |
| 关键词 | 输入框 | 空 | 匹配详情、目标 ID、请求 ID |

按钮：

- 查询：按当前条件刷新列表，页码回到第 1 页。
- 重置：清空条件并刷新默认列表。

## 4. 下方日志表格

表格列：

| 列名 | 展示内容 |
| --- | --- |
| 时间 | 日志发生时间 |
| 日志类型 | 健康档案、登录登出、后台管理等 |
| 操作类型 | 修改健康档案、短信登录、登出等 |
| 终端 | App、PC、后台管理 |
| 结果 | 成功、失败 |
| 操作人 | 用户昵称、管理员名称、脱敏手机号 |
| 操作对象 | 用户、健康档案、配置项等 |
| IP | 客户端 IP |
| 详情 | 脱敏后的操作摘要 |
| 操作 | 查看详情 |

分页区：

- 显示当前范围：例如第 1 - 20 条。
- 显示总数。
- 支持每页 10、20、50、100 条。
- 支持上一页、下一页。

## 5. 详情抽屉

点击“详情”后展示右侧抽屉。

详情字段：

- 日志 ID
- 请求 ID
- 日志类型
- 操作类型
- 操作结果
- 操作人
- 操作对象
- 客户端 IP
- User-Agent
- metadata JSON

健康档案日志详情只展示档案标识，不展示病史、过敏史、字段变更等明文敏感内容。

登录日志详情需要明确显示终端，取值为 App、PC、后台管理。

## 6. 原型评审关注点

评审时建议重点确认：

- 菜单名称使用“日志管理”还是保留“审计日志”。
- 检索条件字段是否足够。
- 表格列是否满足日常排查。
- 是否需要第一期提供日志详情抽屉。
- 是否需要第一期提供导出功能；当前设计未纳入第一期。
- 日志保留周期是否按 365 天执行。
