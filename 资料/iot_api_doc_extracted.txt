2.1.0 开发指南
URL 验证流程
在使用推送服务时，第三方应用需要支持URL 验证以及数据接收两部分服务。
URL 验证流程如下图所示：
用户在配置页面完成配置并点击“提交”时，智慧云平台会向填写URL 地址发送
HTTP GET 请求进行URL 验证,请求形式示例如下：
http://url?nonce=xxx&signature=xxx&timestamp=xxx
其中，url 为用户在页面配置时填写的URL、nonce、timestamp 用于URL 及token 的验证token
验证过程如下：

1、将配置页面中配置的token 与nonce、timestamp 的值计算MD5
2、将上一步中MD5 值通过与请求参数signature 的值进行对比，如果相等则表示token 验证成功如果token
验证成功，返回nonce 参数值，表示URL 验证通过。
3、验证通过后将通过POST 请求方式推送数据
> 注：如果用户不想验证token，可以选择跳过MD5 计算过程，直接返回nonce 参数值
