# ai-backend-dev-pro

Java Spring Boot / AKSO 框架后端开发 Skill（简化流程版）。

## 功能特性

- **知识先行**：编码前必须先阅读并理解项目知识库
- **任务驱动**：从任务拆分目录获取待开发任务
- **循环修复**：验证不通过时自动循环修复
- **进度反馈**：每个步骤完成后主动输出标准化反馈

## 触发关键词

- "开发需求" + 数字
- "实现需求" + 数字
- "后端开发"

## 目录结构

```
ai-backend-dev-pro/

│   ├── workflow-guide.md       # 详细执行步骤
```

## 使用方式

触发技能后，按照 Step 0-6 的流程执行开发任务。

详细步骤请参考 [references/workflow-guide.md](references/workflow-guide.md)。
