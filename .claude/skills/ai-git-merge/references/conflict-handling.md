# Git 冲突处理策略

合并时检测到冲突的处理方式。

## 冲突检测

```bash
git merge <主分支>
```

冲突时显示：
```
⚠️ 检测到冲突：

┌──────────────────────────────────────────────────────┐
│ 冲突文件                                              │
├──────────────────────────────────────────────────────┤
│ src/main/java/.../ValueSetEntity.java                │
│ src/main/java/.../Config.java                        │
└──────────────────────────────────────────────────────┘
```

---

## 处理选项

每个冲突文件，用户选择：

| 选项 | 命令 | 适用场景 |
|------|------|----------|
| 保留本地版本 | `git checkout --ours <file>` | 本地修改更重要 |
| 保留远端版本 | `git checkout --theirs <file>` | 主分支修改更重要 |
| 手动解决 | 用户编辑后 `git add <file>` | 需合并双方修改 |
| 取消合并 | `git merge --abort` | 无法解决 |

---

## 解决后操作

```bash
git add <已解决文件>
git commit -m "merge: 解决冲突"
```

输出：
```
✅ 冲突已解决

• 解决方式: 保留本地版本
• 解决文件: 2 个
```
